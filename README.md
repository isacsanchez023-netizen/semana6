# AE5 - Refactorización de Código Heredado Respaldada por Pruebas

## 1. Descripción del Proyecto
Este repositorio contiene la solución de la **Actividad Evaluada AE5 (Semana 6)** para la asignatura **Diseño de Software (UCOM0310)** de la Universidad Espíritu Santo.

El objetivo del proyecto es transformar de manera segura y controlada un módulo heredado de gestión de reservas mediante refactorizaciones avanzadas. La integridad del sistema se garantiza manteniendo en todo momento una suite de pruebas unitarias en verde desarrolladas con **JUnit 5**, siguiendo el ciclo seguro: **Prueba verde → Cambio pequeño → Prueba verde → Commit**.

---

## 2. Requisitos Previos
* **Java JDK:** Versión 21 o superior.
* **Apache Maven:** Versión 3.8+ o superior.
* **Git:** Para el control de versiones.

Comprueba tus instalaciones desde la terminal:
```bash
java -version
mvn -version
git --version
